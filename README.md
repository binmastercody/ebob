# Binventory eBob Guide

Open `index.html` in a browser. Everything runs from local files (file://), with no server and no internet needed. The only exceptions are the BinMaster support links, which open in a new tab.

## Files
- `index.html`: lesson menu with sections, progress, search and the Setup path
- `emulator.html`: the Binventory Workstation emulator with the guide layer (`?lesson=<id>`, or `?tutorial=db-read-only` / `pending-unknown-status`)
- `doc.html?lesson=<id>`: reading lessons for steps that happen outside the Workstation (installation, networking, upgrades)
- `app/lessons.js`: every lesson (sections, steps, targets, manual references)
- `app/guide.js`: lesson engine (pacing, input guard, Back, Next, progress)
- `app/display.js`: text size, pace, contrast and motion settings (localStorage `ebob-guide-display`)
- `app/guide.css`: all guide styling
- `ebob-sim.js`: the emulator. It is the original, with only pacing hooks added for the two built-in scenarios (generated by `tools/build.mjs`)

Progress is saved in localStorage `ebob-guide-progress`, and the open sections are saved in `ebob-guide-open`.

## Adding a lesson
Add an `L.push({...})` in `app/lessons.js` and put its id in the `ORDER` list.
- A step is `{ title, msg, target, do: "click" | "type" | "select" | "check" | "uncheck" | "read", value, until }`.
- A reading lesson uses `kind: "doc"` and `doc: [{ title, html }]`.

## Testing (from /workspace/ebob/tools)
- `node walk.mjs <lesson ids...>`: clicks through lessons the way a person would
- `node verify.mjs`: checks the menu, pacing, font controls, scenarios, reading lessons and links, and takes screenshots
